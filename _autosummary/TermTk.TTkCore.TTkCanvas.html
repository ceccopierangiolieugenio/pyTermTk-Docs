TTkCanvas:

A low-level drawing surface that stores characters and colors before they are composed into widgets or flushed to the terminal.

Parameters:

  • width (int) – the width of the Canvas

  • height (int) – the height of the Canvas

drawTTkString(pos: ~typing.Tuple[int, int], text: ~TermTk.TTkCore.string.TTkString, width: int | None = None, color: ~TermTk.TTkCore.color.TTkColor = <TermTk.TTkCore.color.TTkColor object>, alignment: ~TermTk.TTkCore.constant.TTkConstant.Alignment = Alignment.NONE, forceColor: bool = False) → None[source]🌶️

Draws a TTkString with alignment and optional color override.

This method keeps a dedicated fast path because text drawing is used in most widgets and needs to minimize conversion overhead.

Parameters:

  • pos (tuple[int, int]) – the top-left position where the string is drawn

  • text (TTkString) – the formatted text object to render

  • width (int | None) – the output width, defaults to the string terminal width

  • color (TTkColor) – an additional color merged with the string colors

  • alignment (TTkK.Alignment) – the alignment used inside width

  • forceColor (bool) – True to ignore embedded string colors and use only color
